# 희망나래장애인복지관 직업지원팀 안내 챗봇

카카오톡 채널에서 동작하는 안내 챗봇이다. 버튼 메뉴로 답하고, 메뉴에 없는 질문은 키워드로 찾아 답한다. 찾지 못하면 문의 전화번호를 안내한다.

## 파일 설명

| 파일 | 역할 | 고쳐야 하나 |
| --- | --- | --- |
| `content.json` | 챗봇이 말하는 모든 문구(메뉴, 답변, 전화번호) | **여기만 고친다** |
| `server.js` | 카카오톡 질문을 받아 답을 돌려주는 프로그램 | 고치지 않는다 |
| `test.js` | 챗봇이 제대로 답하는지 확인하는 시험 | 고치지 않는다 |

## content.json 고치는 법

- 메뉴 하나는 `제목`, `키워드`, `답변` 세 가지로 이루어진다.
- `제목`은 이용자에게 보이는 버튼 이름이다. 14자 이하로 쓴다.
- `키워드`는 이용자가 문장으로 물었을 때 찾을 단어다. 여러 개 적을 수 있다.
- `답변`은 1000자 이하로 쓴다. 줄바꿈은 `\n`으로 적는다.
- `{운영시간}`, `{문의번호}`처럼 중괄호로 쓰면 `기관` 항목의 값으로 바뀐다.
- 메뉴는 한 단계에 최대 9개까지 둘 수 있다.
- 메뉴 안에 `하위` 목록을 넣으면 세부 메뉴가 된다. `장애인일자리사업` 항목이 예시이다.
- 같은 단계에서 이용자가 문장으로 물으면 세부 메뉴의 키워드를 먼저 찾고, 없을 때 상위 메뉴를 보여준다.
- `제목`은 모든 메뉴에서 서로 달라야 한다.
- `"전화버튼": true`를 넣으면 답변 아래에 전화 걸기 카드가 붙는다.
- 메뉴에 `링크`(주소, 카드제목, 카드설명, 버튼, 준비중답변)를 넣으면 답변 아래에 바로가기 버튼 카드가 붙는다. 주소가 `https://`로 시작하지 않으면 `준비중답변`과 전화 카드가 대신 나간다. `상담 신청` 메뉴가 예시이며, 양식 주소를 `주소`에 넣으면 연결된다.
- 번호는 `기관` 항목에 있다. `문의번호`는 기본 번호이고, `고용문의번호`는 고용업무 전용이다. 메뉴에 `"문의번호키": "고용문의번호"`를 넣으면 그 메뉴와 하위 메뉴의 전화 카드가 해당 번호를 쓴다.
- 쉼표, 따옴표, 중괄호를 지우면 오류가 나므로 글자 부분만 고친다.

## 컴퓨터에서 시험하기

```
node test.js      # 자동 시험
node server.js    # 서버 실행 (http://localhost:3000)
```

## 카카오톡 채널 연결 순서

1. 카카오톡 채널 관리자센터(business.kakao.com)에서 채널을 만든다.
2. 챗봇 관리자센터(chatbot.kakao.com)에서 봇을 만들고 채널과 연결한다.
3. 스킬을 등록하고 서버 주소(`https://서버주소/skill`)를 입력한다.
4. 웰컴 블록과 폴백 블록이 모두 이 스킬을 쓰도록 설정한다.
5. 배포 후 채널 채팅방에서 시험한다.

서버를 인터넷에 공개하는 방법은 다음 단계에서 함께 진행한다.
